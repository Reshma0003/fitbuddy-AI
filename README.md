# FitBuddy - AI Fitness Plan Generator

FitBuddy is an AI-powered fitness planning web application.

## Technologies

- Python
- FastAPI
- Jinja2
- SQLAlchemy
- SQLite
- Google Gemini
- HTML
- CSS
- JavaScript

## Features

1. User registration
2. Personalized 7-day workout plan
3. Nutrition/recovery tip
4. Feedback-based plan modification
5. Original and updated plan storage
6. Admin dashboard
7. REST API
8. SQLite database
9. Gemini AI integration
10. Local fallback when Gemini is unavailable
